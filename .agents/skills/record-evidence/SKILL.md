# 결정과 증거 기록

현재 과제에서 실제로 확인한 정보만 기록한다. 개인 메모리, 다른 프로젝트, 외부 자료는 가져오지 않는다.

중요한 결정마다 아래 항목을 짧게 남긴다. 단순 파일 수정마다 기록을 늘릴 필요는 없다.

- 결정: 무엇을 선택하거나 변경했는가?
- 이유: 어떤 요구사항이나 관찰 때문에 선택했는가?
- AI 실행 증거: 실제 실행한 명령, 관련 입력, 종료 코드, 결과 요약. 실행하지 않았다면 `미실행`.
- 사람 확인: 사용자가 직접 확인했다고 명시한 내용만 기록. 없으면 `미확인`.
- 한계와 다음 확인: 검증하지 않은 조건, 남은 실패 또는 불확실성.

기존 작업 기록 파일이 있으면 그 형식을 따른다. 파일로 기록하라는 요청이면 지정한 과제 작업 폴더에 `work-log.md`를 만들거나 갱신한다. 없으면 대화 안에 짧게 정리한다. 원본 입력, 비밀값, 불필요한 개인정보는 기록에 복사하지 않는다. 실패했던 기록을 성공한 것처럼 덮어쓰지 않고 수정 후 결과를 덧붙인다.

AI 사용이 허용된 과제 단계 전용이다. 서술형 평가의 답안·대필·복사용 문구를 생성하지 않는다. 외부 AI·API 키·외부 데이터 서비스·외부 전송·Git push·Computer Use 자동화와 제공 Codex 업데이트를 하지 않는다. 기록은 지정 작업 폴더에만 두고 공개 저장소에 올리지 않는다.
