# 요구사항과 완료 조건

공개 스킬 반입 허용과 사전 작성 프롬프트 반입을 구분한다. 복사·붙여넣기용 요청문을 만들거나 저장소를 사전 멘트 반입의 우회 수단으로 이용하지 않는다. 설명과 예시는 이해용이며, 시험 중 사용자 요청은 본인이 그때 자신의 말로 직접 입력해야 한다. 허용된 스킬 사용과 명령 문법 설명은 유지한다.

사용자가 지정한 과제 작업 폴더와 제공된 요구사항만 읽는다. 개인 PC 파일, 개인 메모리, 외부 자료를 추가로 찾지 않는다.

1. 원하는 결과, 입력과 출력, 제출 형식, 실행 환경, 금지 사항을 요약한다. 확인된 사실과 가정을 구분한다.
2. 완료 여부를 실제로 확인할 수 있는 조건을 정한다. 예: “제공 입력을 실행하면 요구한 열과 행 수의 결과가 나온다.”
3. 결과를 크게 바꿀 미확인 사항만 사용자에게 묻는다. 나머지는 가정을 밝히고 진행한다.
4. 최소 기능을 끝까지 실행할 순서와 검증 방법을 제안한다. 기존 코드가 있으면 재사용할 부분을 먼저 확인한다.

출력은 `목표 / 입력·출력 / 제약 / 완료 조건 / 가정·미확인 / 다음 행동`을 담은 짧은 목록이면 충분하다. 요구사항 정리만 요청받았다면 구현 파일은 수정하지 않는다.

이 스킬은 AI 사용이 허용된 과제 단계 전용이다. 서술형 평가에서는 답변 작성·대필·복사용 문구를 생성하지 않는다. 시험 중 외부 AI·API 키·외부 데이터 서비스·외부 전송·Git push·Computer Use 자동화를 사용하지 않고, 제공 Codex를 업데이트하지 않는다. 반입은 허용된 공개 저장소 방식만 따른다.
